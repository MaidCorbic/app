# Gameplay Expansion V5

Nine additive systems covering twelve audited gameplay ideas:

- Stamina / Endurance
- Field Crafting
- Vehicle Drive + Cargo Loading + Manual Refueling
- Rescue Carry
- Loot Extraction
- Black-Market Trade
- Escort Target
- Field Repair
- Investigation: Evidence Collection + Delivery Inspection

V5 is mission-scoped and pointer/touch-first. It does not register keyboard shortcuts and owns its temporary scene resources for cleanup.
