# World Unknown

Standalone HTML/CSS/JS mystery investigation prototype.

## Gameplay
- Case #001: The Hidden Capital
- 10 selectable countries
- Country files
- 5 evidence categories
- 3 attempts
- Case solved / failed states
- Responsive mobile layout
- No framework or build step

## Files
- index.html — UI
- style.css — visual system
- data.js — case and country data
- game.js — gameplay logic

The folder can be served as a static GitHub Pages directory or copied into a separate repository.
